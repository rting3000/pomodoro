# 🍅 Pomodoro Timer

A beautiful, minimalistic pomodoro timer to boost your productivity.

## ✨ Features

- **25-minute focus sessions** with 5-minute breaks
- **Long breaks** every 4 sessions (15-30 minutes)
- **Clean, distraction-free interface**
- **Audio notifications** for session changes
- **Session tracking** and statistics
- **Customizable timer settings**

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/pomodoro-timer.git

# Navigate to project directory
cd pomodoro-timer

# Open index.html in your browser
open index.html
```

Or simply download the `index.html` file and open it directly in your browser!

## 🛠 Tech Stack

- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS3 with glassmorphism design
- **Audio**: Web Audio API
- **Storage**: localStorage for settings and stats
- **No dependencies**: Runs directly in the browser

## 📱 Usage

1. Click **Start** to begin a 25-minute focus session
2. Work on your task until the timer rings
3. Take a 5-minute break when prompted
4. Repeat for 4 sessions, then enjoy a longer break
5. Track your completed sessions and stay motivated!

## 🎨 Design Philosophy

Simple. Clean. Effective.

This pomodoro timer embraces minimalism to keep distractions at bay and help you focus on what matters most.
